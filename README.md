## 为什么同一个东京机房，价格能差这么多

最直观的例子就是 STARTER。

DMIT 当前东京 **Premium STARTER** 是 1 vCore、2GB 内存、40GB SSD、1000GB 流量，**$45.90/月**。同样是东京 **Tier 1 STARTER**，CPU、内存、SSD 基本对应，但流量给到 **4000GB Max (IN, OUT)**，价格只有 **$12.90/月**。换句话说，你支付的主要不是“更多 CPU”，而是网络路线和流量策略的差价。

TINY 的差距更明显。Premium TINY 是 **$21.90/月、500GB**，Tier 1 TINY 是 **$6.90/月、2000GB Max (IN, OUT)**。两者都是 1 vCore、1GB、20GB SSD。单看硬件，Tier 1 反而给了更多可用流量；Premium 的溢价主要落在网络定位，而不是硬件规格上。

这就是为什么“DMIT 日本价格贵不贵”不能只看最便宜的一档。真正应该问的是：

**你有没有必要为中国大陆优化路线付钱？**

如果你的用户主要在日本本地、韩国、东南亚、美国等地区，网站本身又不依赖中国大陆访问质量，那么 Tier 1 的低价和更高流量额度通常更容易解释得通。

反过来，如果服务器的主要访问用户来自中国大陆，路由质量比每月多几 TB 流量更重要，那么 Premium 才是更值得重点比较的部分。DMIT 官方明确把 Tokyo Premium 定位为通过 CN2 GIA 优化中国大陆访问，而 Tier 1 则明确不提供这类中国专用优化。

## Premium 和 Tier 1，应该先看哪个参数

很多人会先看 vCPU 和内存，但东京 VPS 更容易踩坑的其实是**流量计费和路由**。

Premium 系列从 TINY 到 GIANT，内存从 1GB 一路增加到 24GB，SSD 从 20GB 到 640GB，流量从 500GB 到 15TB，所有当前东京 Premium 方案页面都标注为 1Gbps。

Tier 1 从 WEE 到 GIANT 的配置跨度更大，流量从 **1000GB Max (IN, OUT)** 一直到 **128000GB Max (IN, OUT)**。这里的 “Max (IN, OUT)” 不是“上传和下载加起来算两倍”的意思。DMIT 官方文档把这种计费方式定义为：上传和下载两个方向中，**取较大的一侧作为已使用流量**。

例如：

假设某个月上传 700GB、下载 1800GB，按这种“最大值”逻辑，计入的是 1800GB，而不是 2500GB。

这对备份服务器、镜像、文件中转一类工作负载会非常重要。但别把“流量额度”直接等同于“实际一定跑得到的速度”。DMIT 也明确说明，标注的端口速度属于峰值参考，实际速率仍受 VM 性能、国际链路和本地网络环境影响。

## 购买前最容易忽略的几个限制

### 流量不是永久固定不变

DMIT 官方文档说明，实例的传输额度会按月重置。根据具体产品的规则，超出额度后可能出现暂停、限速，或者没有限制等不同策略；大多数常规方案还支持付费重置流量。

所以，买 VPS 时不要只看“每月多少 GB”，还要看**超量后发生什么**。

对于 Tier 1 东京方案，价格页明确使用 `Max (IN, OUT)` 的展示方式；对于 Premium，则直接显示 500GB、1000GB、2000GB 等额度。

### IPv6 有明确支持，但 IP 并不等于所有服务都能访问

DMIT 官方文档确认，实例默认支持 **/64 IPv6**。同时官方明确提醒，分配的 IP 地址并不能保证一定能够访问某个网站或服务，包括流媒体、游戏以及特定平台。

Tier 1 的限制又更明显一些：官方特别写明，Tier 1 产品分配的 IP **不保证在所有国家或地区都可用**。所以，如果你买东京服务器是因为某个特定地区服务的 IP 属性，下单之前应该把“IP 能不能用”当成独立问题，而不是只看机房位置。

### Root 密码远程登录默认关闭

DMIT 当前文档默认建议通过 SSH Key 登录，远程 Root 密码登录默认关闭。对于刚开始用 VPS 的用户，这意味着购买完成后，登录方式和你以前某些廉价 VPS 的体验可能不一样。

### 退款规则并不是“用了一个月还能全退”

DMIT 当前退款规则是：新服务购买 **3 天内**，且 VM 传输量不超过 **30GB**，符合条件时可以申请全额退款；新订单在 **30 天内**还存在剩余价值退款机制。原支付渠道退款可能扣除支付提供商的手续费，续费订单等情况也有明确的不可退款规则。

这实际上给了新用户一个不错的测试窗口，但它不是让你长期试用。
